# Plot/Reporting Checklist

Generate, for each registered experiment:

- precision/recall/F1 comparison across seeds;
- calibration reliability diagram and ECE/Brier table;
- L1–L5 migration degradation curve;
- modality ablation table;
- time-to-first-evidence, candidate and assessment latency;
- scale profile for 10K/100K/1M synthetic records.

All figures must identify dataset version, split, seed and model version.
